Перетаскивание — поворот, с Shift или правой кнопкой — сдвиг, колесо — масштаб, двойной щелчок — исходный вид. С клавиатуры: стрелки, Shift+стрелки, + и −, 0. Грани, видимые с изнанки, окрашены красным — на исправной сетке их не видно.

Чертёж по последним допустимым значениям: в одном из полей не число или число вне допустимого диапазона.
