# Каталог примеров

Все файлы имеют `schemaVersion: 6`; шкивы GT2 — `kind: "timingPulley"`, гладкие шкивы (файлы `idler-*`) — `kind: "idlerPulley"`, шестерни (файлы `gear-*`) — `kind: "gear"`, косые — `gear-helical-*`, шевронные — `gear-herringbone-*`. Все файлы в `valid/` проходят структуру и связанные правила контракта. Файлы в `invalid/` намеренно демонстрируют один основной отказ; ядро может дополнительно вернуть независимые диагностики. Тест `tests/core.test.js` читает оба каталога целиком: новый недопустимый пример без записанного ожидаемого кода не пройдёт.

Все допустимые примеры, кроме `spokes-flanged.json`, прижимают полотно к низу без сдвига: полотно или спицы, втулка и нижний фланец (без него — нижний торец венца) лежат в одной плоскости. Выступы втулки отсчитываются от плоскостей детали — дальних плоскостей фланцев, а без фланца от торцов венца.

| Файл | Ожидаемый результат | Что покрывает |
| --- | --- | --- |
| `valid/solid-basic.json` | успех + `W_EXPERIMENTAL_PROFILE` | Сплошное полотно без утонения, совпадающие плоскости полотна и венца, нулевые выступы и отсутствие фланцев. |
| `valid/spokes-flanged.json` | успех + `W_EXPERIMENTAL_PROFILE` | Шесть спиц по центру со сдвигом −0,2 мм, обязательные сопряжения, два разных фланца и два выступа втулки. |
| `valid/asymmetric.json` | успех + `W_EXPERIMENTAL_PROFILE` | Полотно 3 мм у нижнего торца (утонение 6 мм), только верхний фланец, нулевой нижний выступ. |
| `valid/trial-20t.json` | успех + `W_THIN_FEATURE`, `W_EXPERIMENTAL_PROFILE` | Пробный шкив: ремень 6 мм, 20 канавок, отверстие ровно 5 мм, сплошное тело на всю высоту вместе с фланцами, два фланца. Предупреждение о тонком венце здесь формальное: полотно сплошное на всю высоту. |
| `valid/trial-60t.json` | успех + `W_EXPERIMENTAL_PROFILE` | Пробный шкив: ремень 6 мм, 60 канавок, отверстие ровно 5 мм, шесть спиц 3 мм заподлицо с нижним фланцем, два фланца; втулка опирается на стол, а сверху кончается у торца венца (выступ −1 мм). |
| `valid/motor-d-flat.json` | успех + `W_EXPERIMENTAL_PROFILE` | 30 канавок под вал шагового двигателя 5 мм: D-образное отверстие 5,2 мм с размером по лыске 4,7 мм, втулка выступает вверх на 4 мм над верхним фланцем. |
| `valid/hex-bore.json` | успех + `W_EXPERIMENTAL_PROFILE` | Шестигранное отверстие 7,5 мм по углам (6,5 мм между гранями), полотно 3 мм у нижнего торца, только верхний фланец. |
| `valid/keyed-spokes.json` | успех + `W_EXPERIMENTAL_PROFILE` | Отверстие 8 мм со шпоночным пазом 2×1 мм, пять спиц 4 мм заподлицо с нижним фланцем, два фланца. |
| `valid/idler-shaft.json` | успех без диагностик | Гладкий шкив на вал 5 мм: обод 16 мм шириной 7 мм под ремень 6 мм, отверстие 5,2 мм, сплошное тело на всю высоту вместе с фланцами, два фланца. |
| `valid/idler-bearing.json` | успех без диагностик | Гладкий шкив под подшипник 625 (5×16×5): обод 28 мм, отверстие 16 мм под наружное кольцо, сплошное тело на всю высоту вместе с фланцами, два фланца. |
| `valid/idler-spokes.json` | успех без диагностик | Гладкий шкив 40 мм под ремень 9 мм: пять спиц 3 мм заподлицо с нижним фланцем, только нижний фланец, втулка выступает вверх на 2 мм. |
| `valid/gear-30t.json` | успех без диагностик | Шестерня с параметрами по умолчанию: модуль 1, 30 зубьев, угол давления 20°, без смещения, утонение 0,1 мм, ширина 6 мм, отверстие 5 мм, сплошное тело. |
| `valid/gear-keyed-20t.json` | успех без диагностик | Шестерня модуля 2 на 20 зубьев (диаметр вершин 44 мм), ширина 10 мм, отверстие 8 мм со шпоночным пазом 3×1,4 мм, сплошное тело. |
| `valid/gear-motor-12t.json` | успех без диагностик | Шестерня на вал шагового двигателя: модуль 1,5, 12 зубьев со смещением 0,3 — без него выдавалось бы `W_GEAR_UNDERCUT`; D-образное отверстие 5,2 мм с размером по лыске 4,7 мм, втулка выступает вверх на 5 мм. |
| `valid/gear-spokes-60t.json` | успех без диагностик | Шестерня модуля 1,5 на 60 зубьев (диаметр вершин 93 мм): основная окружность ниже окружности впадин, шесть спиц 4 мм у нижнего торца, втулка выступает вверх на 3 мм. |
| `invalid/hub-wall.json` | `E_HUB_WALL` | Отверстие оставляет стенку тоньше 1 мм. |
| `invalid/idler-no-interior.json` | `E_RIM_NO_INTERIOR` | Гладкий шкив: толщина обода 6,5 мм больше его радиуса 6 мм; путь диагностики — `/rim/outerDiameter`. |
| `invalid/bore-flat.json` | `E_BORE_FLAT` | Размер по лыске больше диаметра отверстия. |
| `invalid/bore-key.json` | `E_BORE_KEY` | Шпоночный паз не уже отверстия. |
| `invalid/radial-order.json` | `E_RADIAL_ORDER` | Втулка оставляет меньше 0,5 мм до внутреннего радиуса венца при сплошном полотне. |
| `invalid/web-outside-rim.json` | `E_WEB_AXIAL_RANGE` | Полотно по центру, сдвинутое на 2 мм, частично выходит выше детали. |
| `invalid/web-too-thin.json` | `E_WEB_THINNING`, `W_THIN_FEATURE` | Утонение 5,5 мм при высоте детали 6 мм оставляет полотно 0,5 мм — тоньше 1 мм. |
| `invalid/hub-short.json` | `E_HUB_SHORT` | Выступ втулки вниз −1 мм: втулка кончается у торца венца, а полотно прижато к нижнему фланцу на 1 мм ниже. |
| `invalid/spoke-overlap.json` | `E_SPOKE_OVERLAP` | Спицы и сопряжения перекрываются у втулки. |
| `invalid/spoke-fillet.json` | `E_SPOKE_FILLET` | Радиус сопряжения больше половины ширины спицы. |
| `invalid/gear-thin-tooth.json` | `E_GEAR_TOOTH_THIN`, `W_THIN_FEATURE` | Шестерня модуля 0,3 с утонением 1 мм — больше толщины зуба; дополнительно тонкий венец 1 мм. |
| `invalid/gear-flange.json` | `E_SCHEMA_VALUE` | Шестерня с нижним фланцем: у шестерни фланцы должны быть `null`, путь диагностики — `/flanges/lower`. |
| `invalid/schema-extra-field.json` | `E_SCHEMA_VALUE` | Неизвестное поле; пример намеренно не проходит JSON Schema. |

Готовые варианты шестерён на странице вариантов — `gear-keyed-20t`, `gear-motor-12t` и `gear-spokes-60t`; `gear-30t` остаётся только примером. Пары шестерён среди примеров нет: проверка межосевого расстояния и зацепления ещё не реализована.

Пробные шкивы экспортируются в положении `onBed`: нижний фланец, полотно или спицы и втулка лежат на столе, поддержки не нужны. Верхний фланец нависает над канавками и выступает на 1,5 мм за вершины зубьев — это единственный заметный навес.

Сборка каталога — STL, сводка `catalog.json`, при наличии Blender — независимая проверка и картинки:

```powershell
node tools/build-catalog.js out/catalog "--blender=C:\Program Files\Blender 4.5\blender.exe"
```

Примеры не содержат ожидаемую сетку и не доказывают пригодность к печати; посадку ремня и вала, а также зацепление шестерён подтверждает только пробная печать.
