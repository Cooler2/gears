# Contributing / Участие

Pull requests and issues are welcome: bug reports, fixes, new part kinds, translations. Without a GitHub account, write to the author: <ivan@apus-software.com>.

Before a pull request, run `node --test`; all tests must pass. Keep the core (`src/core/`) free of browser APIs and dependencies. A change of the description format goes to `docs/contract.md`, the schema and the examples first.
